# MNIST Handwritten Digit Recognition

## Project Overview

This project focuses on recognizing handwritten digits using the MNIST dataset. It explores different Machine Learning and Deep Learning techniques for classifying handwritten digits from 0 to 9.

## Dataset

The MNIST dataset contains images of handwritten digits.

Each image represents one digit from 0 to 9 and is used to train classification models.

## Project Workflow

- Loading the MNIST dataset
- Exploring the dataset
- Visualizing handwritten digit images
- Checking class distribution
- Analyzing pixel values
- Data preprocessing
- Image normalization
- Model training
- Model evaluation

## Machine Learning Models

The project includes the following models:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest

## Deep Learning Model
